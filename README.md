# Hello World

A simple to-do list app.

Add a task. Tick it off. That's it.

- Works offline. Everything is stored in your browser.
- No account, no sign-up, no tracking, no network calls.
- Keyboard friendly. Light and dark themes.
- Comes with a small toolbox of handy calculators and utilities.

**[Open Hello World](https://pragyaangaur.github.io/Hello-World/)**

## Running it locally

There is no build step and there are no dependencies. Clone it and serve the
folder with anything that speaks HTTP.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Tech

Plain HTML, CSS, and JavaScript modules. No frameworks, no bundler, no
package.json. It is a static site, so it deploys straight to GitHub Pages from
the default branch.
